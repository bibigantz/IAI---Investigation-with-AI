{% elif active_tab == 'llm' %}
LLM Provider Configuration

Every agent's analysis step and the Findings-page "Deep Analyze" enrichment action read this config. Defaults point at a local Open WebUI instance's OpenAI-compatible API so the platform runs with zero external network access.

Setting up Open WebUI as the offline provider:
  1. In Open WebUI, go to Settings → Account → API Keys and generate a key.
  2. Base URL is Open WebUI's own address plus /api (e.g. http://localhost:3000/api for the default Docker quick-start — adjust the host/port to match how your instance was actually deployed).
  3. Model name must exactly match a model registered in that Open WebUI instance (check its model picker).
Google AI Studio / Gemini — for testing only, requires internet access.
  1. Get a free API key at aistudio.google.com/apikey (Google AI Studio).
  2. Paste it into API key below.
  3. This makes real outbound HTTPS calls to Google's servers on every agent analysis and every enrichment — not suitable for an offline/air-gapped deployment. Switch back to the Open WebUI preset for real investigations.

{% elif active_tab == 'triage' %}
Fast-Pass Severity Triage

An optional, local "System One" pre-filter that runs ahead of the deep generative LLM pipeline. When enabled, each agent's raw artifact payload is scored for severity by a small local model first; only artifacts meeting the threshold below are forwarded for full generative analysis, saving tokens and keeping low-severity noise out of the deep pipeline's context window. Disabled by default -- this never replaces or overrides the LLM Provider Configuration above, and if the local triage service is unreachable, every artifact silently falls back to the standard pipeline with zero disruption.
