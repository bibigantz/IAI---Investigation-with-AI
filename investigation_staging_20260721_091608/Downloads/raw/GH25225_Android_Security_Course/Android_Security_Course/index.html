Tools, scripts, course documents

JADX (decompiler)

Pre-installed on each lab PC by the college. Open from the Start menu (search "jadx"). Drag any APK onto the window — decodes Java/Kotlin and the manifest into readable form.

Ghidra (native RE)

Pre-installed on each lab PC by the college. Open from the Start menu (search "ghidra") or run ghidraRun.bat from its install folder. Used in the hard-coded native drill for .so analysis.

apktool

Pre-installed on each lab PC by the college. Run from any terminal: apktool d <apk> -o <outdir> unpacks an APK into smali + resources + manifest.

dex-tools

dex-tools-v2.4/. Convert DEX ↔ JAR for Java tooling: d2j-dex2jar.bat / d2j-jar2dex.bat.

find_apps_by_signature.sh

macOS/Linux script that pulls every APK off the device and groups by signing-cert SHA-256. See drill walkthrough.

GetPackages.ps1

Windows PowerShell equivalent. Auto-detects JAVA_HOME / adb / latest apksigner. Handles build-tools 37+ output format.

CyberChef (browser)

Open gchq.github.io/CyberChef in any browser. No install. Used heavily in the hard-coded native drill.

Burp Suite Community

Download from portswigger.net. Used for the MITM drill (Day 4).
